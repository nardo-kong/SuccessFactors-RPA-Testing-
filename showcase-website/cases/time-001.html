TIME-001 Passed Time Management

Enter Overtime — OT Recording and Approval

Validates the complete overtime recording and approval process: the HR operator proxies as an employee to record OT hours, then proxies as the line manager to approve the OT request, confirming the approved record is visible in the Time Sheet.

Test Objective

Validate the end-to-end overtime recording and single-step manager approval process in SAP SuccessFactors Time Management. The test verifies that OT hours can be entered into an employee's Time Sheet, the OT record is captured before approval, the manager can approve the OT request, and the approved record is correctly reflected in the system.

Overtime Recording Manager Approval Time Sheet Verification
📋
Prerequisites
✓
Target employee has an active Time Sheet for the test period with OT recording enabled for their employee group
✓
HR operator account has proxy capability for both the employee and the designated manager
✓
OT date and hours to be recorded are loaded in UiPath Data Service as test parameters
✓
Manager is configured as the direct approver for the employee's OT requests
🔬
Test Steps
1
GIVEN
System Authentication
Log in to SAP SuccessFactors with RPA service account. Retrieve credentials from Orchestrator. Verify home page loads.
2
WHEN
Proxy as Employee — Navigate to Time Sheet
Proxy into the designated employee's account. Navigate to Time Management → Time Sheet. Open the current period's Time Sheet. Verify the sheet is editable.
✓ Proxy to Employee successful
3
WHEN
Record OT Hours
Locate the target OT date in the Time Sheet grid. Select the OT time type from the dropdown. Enter the OT hours from test data. Add any required comments. Click Save to record the OT entry. Capture the pre-approval state of the OT record as evidence.
✓ OT Record Captured (before approval)
4
WHEN
Proxy as Manager — Approve OT Request
Switch proxy to the employee's line manager. Navigate to the Time Management approval inbox or Team Time Management. Locate the pending OT approval request for the target employee. Review the OT entry details (date, hours, type). Click Approve.
✓ Proxy to Manager successful✓ OT Approval Successful
5
THEN
Verify Approved OT Record
Return to the employee's Time Sheet (proxy back if necessary). Verify the OT entry status has changed to "Approved". Capture a screenshot of the approved OT record as test evidence.
✓ Approved OT Record Captured
✅
Expected Results
✅
OT hours recorded without validation error
The OT time entry is saved in the Time Sheet with correct date, hours, and time type.
✅
Manager approval processed successfully
The approval request is visible to the manager and can be approved in a single action.
📊
OT record status = Approved. All 5 assertions pass (5/5).
