EC-001 Passed Employee Central Job Structure

Create and Maintain Jobs — Job Family & Job Code

Validates the creation and subsequent update of Job Family and Job Code records in the SAP SuccessFactors Job Structure configuration, ensuring that the system correctly stores, retrieves, and updates these foundational HR data objects.

Employee Central

Test Objective

Verify that an HR administrator can successfully create new Job Family and Job Code records in the SAP SuccessFactors Job Structure module, verify their persistence, and then update both records. This test covers the create and maintain lifecycle for two foundational job structure objects that are prerequisite to position and employee data management.

Job Structure Job Family Job Code CRUD Validation
📋
Prerequisites
✓
Admin account with permission to manage Job Structure objects (Job Family and Job Code) is available
✓
New Job Family name, code, and description are prepared and unique (not already in the system)
✓
New Job Code name, code, and associated Job Family are defined in the test data
✓
Updated values for both Job Family and Job Code are prepared for the maintenance step
🔬
Test Steps
1
GIVEN
System Authentication
Log in to SAP SuccessFactors using admin credentials retrieved from UiPath Orchestrator. Verify successful login.
2
WHEN
Navigate to Job Structure
Navigate to Admin Center → Configure Object Definitions → Job Structure (or equivalent menu path). Verify the Job Structure management page loads correctly.
✓ Navigate to Job Structure
3
WHEN
Create New Job Family
Click "Create New" for Job Family. Enter the Job Family code, name (English), and description. Set the status to Active and save the record. Verify the creation confirmation message is displayed.
✓ Job Family Created
4
WHEN
Create New Job Code
Navigate to the Job Code section. Click "Create New". Enter the Job Code, title, and link it to the newly created Job Family. Set grade and status. Save the record and verify the creation confirmation.
✓ Job Code Created
5
WHEN
Verify Both Records
Search for the newly created Job Family and Job Code by their respective codes. Verify that the records appear in search results with correct data and Active status.
✓ Job Family Verified✓ Job Code Verified
6
WHEN
Update Job Family
Open the Job Family record and modify the description field with updated text (as per test data). Save the changes and verify the update confirmation is displayed.
✓ Job Family Updated
7
WHEN
Update Job Code
Open the Job Code record and update the job title or external name field (as per test data). Save the changes and verify the update confirmation.
✓ Job Code Updated
8
THEN
Final Verification
Retrieve both updated records and verify the changes are persisted correctly. Confirm all fields display the updated values. Screenshot captured as evidence.
✓ Final Verification Complete
✅
Expected Results
Records created successfully: Both Job Family and Job Code are created with correct data and appear in search results immediately after creation.
Updates persisted: Modifications to both Job Family and Job Code are saved and reflected accurately when records are retrieved.
All 9 assertions pass (9/9): No validation errors, system exceptions, or data integrity issues encountered throughout the test.
