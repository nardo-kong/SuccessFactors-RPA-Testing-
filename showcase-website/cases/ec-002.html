EC-002 Passed Employee Central Position Management

Create Position — Position Org Chart

Validates the complete position creation workflow: a new position is created with full organisational and job requirement data via the Position Org Chart, submitted for approval, processed through a five-level approval chain, and confirmed as Active upon completion.

POC Reference
POC:303
Assertions
14 Passed / 0 Failed
Duration
00:07:09
Executed
2026-05-21
Automation
UiPath RPA (BDD)
🎯
Test Objective

Validate that a new headcount position can be created through the SAP SuccessFactors Position Org Chart interface, with all required data sections completed — including basic position information, organisational assignment, and job requirements. The test further verifies that the creation request is successfully routed through the configured five-level approval chain and that the position transitions to Active status upon final approval.

Position Creation Org Chart Navigation 5-Level Approval Status Verification
📋
Prerequisites
✓
HR administrator account with permission to create and submit new positions in the Position Org Chart
✓
Target parent position and reporting hierarchy pre-configured in the Org Chart for the new position to be inserted under
✓
Job Code and Job Classification that will be assigned to the new position are already active in Job Structure
✓
Position creation approval workflow configured with five approvers covering HR, Finance, and executive levels
✓
Position data (title, code, effective date, FTE, location, department, division) loaded in UiPath Data Service as test parameters
🔬
Test Steps
1
GIVEN
System Authentication
Log in to SAP SuccessFactors with HR admin credentials retrieved from UiPath Orchestrator. Verify the home dashboard loads before proceeding.
2
WHEN
Navigate to Position Org Chart
From the navigation menu, go to Admin Center → Position Org Chart. Search for and locate the parent department node under which the new position will be created. Verify the org chart renders correctly.
✓ Navigate to Position Org Chart
3
WHEN
Initiate New Position Creation
Right-click or use the context menu on the parent node to select "Add Direct Report" or "Create New Position". The new position form opens. Set the Effective Date from test data.
✓ New Position Form Opened
4
WHEN
Enter Basic Position Information
Complete the Basic Information section: (1) Position Code (system-generated or manually entered), (2) Position Title, (3) Position Type = Regular, (4) FTE = 1.0, (5) Max Occupancy = 1, (6) Effective Date. Save this section.
✓ Basic Position Info Saved
5
WHEN
Enter Organisational Data
Complete the Org Data section: (1) Company / Legal Entity, (2) Business Unit, (3) Division, (4) Department, (5) Location, (6) Cost Centre (if applicable). Verify all dropdowns are selected from valid configured values. Save.
✓ Org Data Saved
6
WHEN
Enter Job Requirements
Complete the Job Requirements section: (1) Job Classification (linked to Job Code), (2) Employee Class, (3) Regular/Temporary flag, (4) Rostered / Non-Rostered designation, (5) Pay Grade. Save the section.
✓ Job Requirements Saved
7
WHEN
Submit Position Request — Retrieve Approval List
Review all three data sections. Click "Save and Submit" to initiate the position creation workflow. The system dynamically builds the approval routing. Capture and verify the returned approver list contains all expected participants.
✓ GetApprovalList✓ Position Submitted
8
WHEN
Approval — Steps 1 through 5
Sequentially proxy as each of the five approvers in the workflow chain. At each step: (1) proxy into the approver's account, (2) navigate to the workflow inbox, (3) locate the position creation request, (4) review position details (title, org data, job requirements, FTE), (5) click Approve. Repeat for all five approvers until the chain is fully completed.
✓ Approve Step 1 Successful ✓ Approve Step 2 Successful ✓ Approve Step 3 Successful ✓ Approve Step 4 Successful ✓ Approve Step 5 Successful
9
THEN
Verify Position is Active in Org Chart
Return to the Position Org Chart and search for the newly created position by its position code. Verify: (1) Position appears in the org chart under the correct parent node, (2) Status shows "Active", (3) All data fields (title, org assignment, job requirements) match the submitted values. Screenshot captured as evidence.
✓ Position Active — Verified
✅
Expected Results
✅
All three data sections saved without errors
Basic Info, Org Data, and Job Requirements each save successfully with confirmation indicators.
🔄
Complete 5-level approval chain processed
The position request routes through all five approvers in the correct sequence without interruption or routing failure.
📍
Position status transitions to Active
After final approval, the new position is visible in the Position Org Chart with status Active and all data fields correctly populated.
