EC-008 Employee Central Mainland China Multi-Role Proxy

New Hire Onboarding — Mainland China (MCN)

Validates the complete new employee onboarding workflow for the Mainland China legal entity, covering all personal data sections, national ID entry, MCN-specific address fields, bank account, compensation, and the post-submission approval and employee ID creation process.

Module
Employee Central
Assertions
25 Assertions
Automation
UiPath RPA (BDD)
🎯
Test Objective

Validate the end-to-end new hire creation process for the Mainland China (MCN) legal entity. The test confirms that all mandatory personal, employment, and compensation data sections can be populated correctly, that the new hire workflow is successfully submitted and approved, and that a valid Employee ID is generated upon approval. MCN-specific data requirements — including national ID type (CHN Resident Identity Card), CN/EN dual-name input, CNY currency, and Province/City/District address hierarchy — are specifically exercised in this test case.

New Hire Workflow MCN Legal Entity Employee ID Generation Proxy Multi-Role
📋
Prerequisites
✓
A vacant, active position exists in the Mainland China org chart for the new hire to be mapped to
✓
HR Manager, HR Deputy Manager, and Senior HR Officer accounts exist with appropriate permissions and proxy capability
✓
New hire personal data prepared: full CN/EN legal name, national ID number, address (Province/City/District), phone, email, emergency contact, bank account
✓
Job and compensation configuration for MCN legal entity is complete (pay grade, CNY currency, pay component)
✓
New hire approval workflow is configured with HR Approver as the approver for new hire requests
✓
Employee ID number range for MCN is configured and available in SAP SuccessFactors
🔬
Test Steps
1
GIVEN
System Authentication
Navigate to the SAP SuccessFactors tenant URL. Retrieve automation credentials from UiPath Orchestrator. Complete login and verify successful session establishment.
2
GIVEN
Proxy as HR Manager — Verify Position Exists
Proxy as the HR Manager (Shared Services). Navigate to Position Org Chart and search for the target vacant position by position code. Verify the position status is Active and Vacant.
✓ Proxy to HR Manager successful✓ Position verified as Active/Vacant
3
GIVEN
Proxy as HR Deputy Manager — Confirm Position
Switch proxy context to the HR Deputy Manager. Re-confirm the position exists and is eligible for new hire assignment. This step simulates the pre-hire position verification by a secondary HR role.
✓ Proxy to HR Deputy Manager successful
4
WHEN
Proxy as Senior HR Officer — Initiate New Hire
Switch proxy to the Senior HR Officer who will perform data entry. Navigate to Admin Center → Manage New Hires → Add New Employee to launch the new hire wizard.
✓ Proxy to Senior HR Officer successful
5
WHEN
Enter Basic Employment Data
In the new hire wizard, select Legal Entity: Mainland China. Enter Hire Date, Employee Class, and Position code. The system auto-populates department, division, and reporting line from the position configuration.
✓ Basic Data Saved
6
WHEN
Enter Name Information
In the Personal Info section, enter the employee's legal full name in both Chinese characters (Legal Chinese Name) and English (Legal English Name). First name, last name, and preferred name fields are all populated per MCN requirements.
✓ Name Saved
7
WHEN
Enter National ID
Select ID Type: CHN Resident Identity Card. Enter the national ID number. Set the country of issue and confirm the ID record. This is a mandatory field for MCN employees and triggers specific validations in SAP SuccessFactors.
✓ National ID Saved
8
WHEN
Enter Gender and Marital Status
Select the employee's gender and marital status from the configured dropdown values. These fields are required for MCN payroll and compliance reporting.
✓ Gender and Marital Status Saved
9
WHEN
Enter Contact Information
Enter the employee's business email address and mobile phone number. Email is validated for format; phone is entered with country code prefix.
✓ Email Saved✓ Phone Saved
10
WHEN
Enter Residential Address (MCN Hierarchy)
Select Residential address fields using the MCN-specific hierarchical structure: Province → City → District → Street / Detailed Address. This three-tier geographic hierarchy is unique to Mainland China entities.
✓ Residential Address Saved
11
WHEN
Enter Correspondent Address
Enter the employee's correspondent (mailing) address. If the same as residential, the system allows copying. A different address is entered to verify independent storage of both address types.
✓ Correspondent Address Saved
12
WHEN
Enter Emergency Contact
Add emergency contact record: name, relationship, and phone number. This is a mandatory data section before the new hire record can be submitted.
✓ Emergency Contact Saved
13
WHEN
Enter Bank Account Details
Enter the employee's payroll bank account: bank name (selected from MCN bank list), bank branch, account number, and account holder name. CNY is auto-selected for MCN legal entity.
✓ Bank Account Saved
14
WHEN
Enter Job Information
Confirm job information fields: Job Code, Department, Division, Location, and Employment Type. These may be auto-populated from the position but must be verified and confirmed before submission.
✓ Job Information Saved
15
WHEN
Enter Compensation Information
Enter the employee's compensation: Pay Grade, Pay Component (e.g., Base Salary), amount, and frequency. Currency is CNY for MCN entity. Confirm the compensation record is saved.
✓ Compensation Saved
16
WHEN
Submit New Hire Request
Review all completed sections. Click "Submit" to initiate the new hire workflow. The system retrieves and displays the approval chain. Verify the approver list is populated correctly.
✓ Get Approvers✓ New hire workflow created
17
WHEN
Proxy as HR Approver — Approve New Hire
Proxy as the configured HR Approver. Navigate to the workflow inbox and locate the new hire approval request. Review all data sections and click Approve. The system processes the approval and triggers Employee ID generation.
✓ Proxy to HR Approver✓ New hire approved
18
THEN
Verify Employee ID Generated
After approval, the system auto-assigns an Employee ID from the configured number range. Navigate to the new employee's profile and verify that a valid, unique Employee ID is displayed.
✓ Employee ID Created
19
THEN
Screenshot Verification — All Profile Tabs
Navigate through the new employee's profile and capture screenshots of all key tabs: Personal Information, Employment Details, Job Information, and Leave Information. These screenshots serve as test evidence and are attached to the test result report.
✓ Personal Information tab captured ✓ Employment Details tab captured ✓ Job Information tab captured ✓ Leave Information tab captured
✅
Expected Results
All data sections saved: Each of the 12 personal and employment data sections is saved without validation errors. System displays a green confirmation indicator for each saved section.
Workflow created and approved: The new hire workflow is generated with the correct approver, the approval is processed successfully, and the workflow status changes to "Completed".
Employee ID assigned: A unique Employee ID is auto-generated and visible in the employee profile after approval. The new employee record is fully active in the system.
All 25 assertions pass: Every assertion check in the test case returns a Passed result (25/25).
