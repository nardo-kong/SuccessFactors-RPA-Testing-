EC-012 Employee Central 2-Level Approval Employment

Probation Management — Status Completion

Validates the automated probation completion workflow: HR operator updates the employee's probation status to "Completed", submits the change request, and the system routes it through a two-level approval chain before updating the employee's job record.

Module
Employee Central
Assertions
5 Assertions
Automation
UiPath RPA (BDD)
🎯
Test Objective

Verify that an HR operator can change an employee's probation status to "Completed" via the Change Job and Compensation Info action, that the resulting workflow is correctly routed through a two-level approval chain, and that the employee's Job Information history is updated with the correct effective date upon final approval.

Probation Status Update 2-Level Approval Job Record Verification
📋
Prerequisites
✓
Target employee is in an active probation period with Probation Status currently set to "In Progress"
✓
HR operator account has proxy capability and permission to submit job and compensation change requests
✓
Probation completion approval workflow is configured with two sequential approvers
✓
Effective date for the probation completion and employee identifier loaded in UiPath Data Service
🔬
Test Steps
1
GIVEN
System Authentication
Log in to SAP SuccessFactors using RPA service account credentials from the Orchestrator credential store. Verify the home dashboard loads before proceeding.
2
GIVEN
Proxy as HR Operator
Use the proxy function to adopt the designated HR operator's identity. Verify the correct user context is displayed before navigating to the employee profile.
3
WHEN
Navigate to Employee Profile
Use the People Search function to locate the target employee by Employee ID. Open the People Profile and navigate to the Employment Information section.
4
WHEN
Initiate Job Change — Update Probation Status
Click "Take Action" → "Change Job and Compensation Info". Set the effective date from test data. In the Job Information section, locate the Probation Status field and change the value to "Completed". Save the change.
✓ Data Change Saved
5
WHEN
Submit Request — Retrieve Approval List
Review the change summary. Click Submit to send the probation completion request for approval. The system generates the approval routing list. Capture and verify that both required approvers are included.
✓ GetApprovalList
6
WHEN
Approval — Step 1
Proxy as the first approver. Navigate to the workflow inbox, locate the probation completion request, review the change details (employee, effective date, new status), and click Approve.
✓ Approver 1 Approval Successful
7
WHEN
Approval — Step 2 (Final)
Proxy as the second and final approver. Locate the pending request in the workflow inbox. Review and click Approve. The system finalises the change and updates the employee's Job Information record.
✓ Approver 2 Approval Successful
8
THEN
Verify Probation Status Updated in Job History
Return to the employee's Job Information History. Verify that a new record dated with the effective date shows Probation Status = "Completed". Workflow status is "Completed". Screenshot captured as test evidence.
✅
Expected Results
✅
Probation status change accepted without errors
The change to "Completed" is saved and a confirmation message is displayed.
🔄
Both approvers complete approval in sequence
No escalation or routing failures. The workflow proceeds from Approver 1 to Approver 2 correctly.
📊
Job Information History updated. All 5 assertions pass (5/5).
