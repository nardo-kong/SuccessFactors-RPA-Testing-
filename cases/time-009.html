TIME-009 Time Management Sick Leave Multi-Role Proxy

Request Leave — Sick Leave Submission & Approval

Validates the complete sick leave request and approval workflow: the HR operator proxies as the employee to submit a sick leave request, then proxies as the manager to approve it, and confirms both future and past leave records are correctly updated after approval.

Module
Time Management
Assertions
8 Assertions
Automation
UiPath RPA (BDD)
🎯
Test Objective

Validate that a sick leave request can be submitted on behalf of an employee and approved by the designated manager within SAP SuccessFactors Time Management. The test verifies the full proxy-based workflow: leave submission, manager approval, and post-approval confirmation of both future leave entitlements and past leave transaction records to ensure accurate leave balance management.

Sick Leave Request Manager Approval Leave Balance Verification Proxy Multi-Role
📋
Prerequisites
✓
Target employee has an active leave entitlement for Sick Leave (SL) type with sufficient balance for the requested dates
✓
HR operator has proxy capability for both the employee and the designated approving manager
✓
Leave request dates, leave type (Sick Leave), and employee identifier loaded in UiPath Data Service
✓
Approving manager is configured as the leave approver for the target employee in the organisational hierarchy
✓
Leave management module is active and accessible for the employee's legal entity and employee group
🔬
Test Steps
1
GIVEN
System Authentication
Log in to SAP SuccessFactors using RPA service account credentials retrieved from UiPath Orchestrator. Verify the home dashboard loads before proceeding with proxy actions.
2
WHEN
Proxy as Employee — Navigate to Leave Request
Proxy into the designated employee's account. Navigate to Time Management → Absence → Request Leave (or equivalent path). Verify the leave request form is accessible and the employee's current leave balance is displayed.
✓ Proxy to Employee successful
3
WHEN
Submit Sick Leave Request
On the leave request form: (1) Select Leave Type = Sick Leave (SL) from the dropdown, (2) Enter the leave start date and end date from test data, (3) Confirm the system calculates the number of leave days correctly (excluding weekends/public holidays), (4) Add any mandatory comments or attachments required for sick leave. Click Submit to send the request for approval.
✓ Sick Leave Request Submitted
4
WHEN
Proxy as Approving Manager
Switch proxy to the designated approving manager. Navigate to the approval inbox (Team Absence or Workflow Inbox). Locate the pending sick leave request for the target employee. Review the request details: employee name, leave type, dates, and number of days.
✓ Proxy to Approver successful
5
WHEN
Approve Leave Request
Review all leave request details in the approval form. Click Approve. Verify the system displays an approval confirmation message and the request status changes from "Pending" to "Approved".
✓ Leave Approved
6
THEN
Return Proxy to Employee — Capture Future Leaves
Switch proxy back to the employee's account. Navigate to the Leave Overview or Absence Calendar. Capture a screenshot of the employee's future leave schedule, confirming the approved sick leave dates appear as booked/approved in the upcoming leave view.
✓ Return Proxy to Employee✓ Future Leaves Captured
7
THEN
Capture Past Leave Records
Navigate to the Leave History or Absence History section. Capture a screenshot of the employee's past leave records, confirming the sick leave transaction is listed with status "Approved" and the correct deduction from the leave balance is shown.
✓ Past Leaves Captured
8
THEN
Confirm Sick Leave Requested and Approved
Perform final verification: (1) Leave request status shows "Approved", (2) Leave balance for Sick Leave type reflects the deduction, (3) Both future leave calendar and past leave history show the correct records. Capture final confirmation screenshot as test evidence.
✓ Sick Leave Requested and Approved — Confirmed
✅
Expected Results
✅
Sick leave request submitted without errors
Leave type, dates, and day count are accepted by the system. The request is queued for manager approval.
🔄
Manager approves in a single action
The leave request is visible in the manager's approval inbox and can be approved without errors.
📋
Leave records updated correctly
Both future leave calendar and past leave history reflect the approved sick leave. The SL balance is correctly deducted.
📊
All 8 assertions pass (8/8).
